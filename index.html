Format & rules

Data

Everything is stored in this browser only (localStorage). Export a backup after every session — especially if you switch devices.

Share with students

The student board (board.html) is read-only — standings, schedule and each student’s own record, with no way to change a score.

The link carries the whole tournament inside it, so it works the moment you paste it into the class group chat — send a fresh one after each session. data.json is for the repository: commit it next to board.html and the board picks it up on its own, refreshing every 30 seconds.

Rules in play

  • Every match is doubles — pairs are drawn from within each team.
  • Rally scoring: a point is awarded on every rally, whoever serves.
  • Game to 11, win by 2, hard cap 15.
  • Teams switch ends when a side first reaches 6.
  • Serve passes to the other side whenever the receiving side wins the rally.
  • Partners rotate: no student is paired with the same teammate twice.
  • Team tie = 3 doubles games; the team winning most games takes the tie.
